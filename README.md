## Featured Projects

### 1. Food Bacteria Statistical Analysis

An R-based analysis of bacterial counts in chilled and non-chilled food samples, exploring distributions, differences between groups, and variation across temperature categories.

**Methods and tools**
- Data cleaning and exploratory data analysis
- Descriptive statistics and data visualization
- Shapiro-Wilk normality testing
- Wilcoxon rank-sum testing
- Kruskal-Wallis and pairwise comparisons

**Project files:** [View the Food Bacteria Analysis folder](R/Food-Bacteria-Analysis/)

The project folder will contain the R source code, dataset where sharing is permitted, output tables, visualizations, and research report.
