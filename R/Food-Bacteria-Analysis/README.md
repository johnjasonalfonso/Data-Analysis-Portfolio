
# Food Bacteria Statistical Analysis

An R-based statistical analysis of bacterial counts in chilled and non-chilled food samples.

## Project Contents

- `analysis.R` — R analysis script
- `data/bacteria_data.csv` — dataset
- `results/figures/` — visualizations
- `results/tables/` — statistical output tables
- `Results.docx` — analysis report

## Methods

- Exploratory data analysis
- Descriptive statistics
- Shapiro-Wilk normality tests
- Wilcoxon rank-sum test
- Kruskal-Wallis test and pairwise comparisons

## Reproducibility

Run the R script from the project root in RStudio. The script uses relative paths to access the dataset and save the results.
