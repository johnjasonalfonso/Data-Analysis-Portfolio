# Attrition Analytics – R Shiny Application

## Project Overview

An interactive R Shiny application developed for attrition analytics.

The project demonstrates the use of R Shiny to build an interactive analytical interface, allowing users to explore attrition-related data and present analytical results through a web-based application.

## Project Objectives

- Develop an interactive application for attrition analytics.
- Organize and present attrition-related information through a user-friendly interface.
- Demonstrate the application of R programming and Shiny for analytical reporting and visualization.

## Application

The application is developed using R and the Shiny framework.
