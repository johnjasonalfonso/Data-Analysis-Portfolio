# Automated File Copying and Renaming Using SAS

## Project Overview

This project demonstrates how SAS macro programming can streamline recurring file-transfer operations between directories or server locations.

## Key Features

- Accepts configurable source and destination paths.
- Supports copying specified files or using wildcard patterns.
- Creates the destination directory when needed.
- Supports optional renaming after copying.
- Writes status messages to the SAS log.

## Technical Skills

- SAS macro programming
- Parameterized automation
- Windows command execution
- File and directory management

## Business Value

Standardizes repetitive file-copying tasks and supports more consistent file handling through a reusable macro.

## Requirements

A compatible Windows environment, SAS command execution permissions, and appropriate access to source and destination directories.

## Security Note

Use anonymized paths and exclude confidential banking data, credentials, and internal server details from the public version.
