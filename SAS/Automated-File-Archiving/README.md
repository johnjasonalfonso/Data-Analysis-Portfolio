# Automated File Archiving and Extraction Using SAS

## Overview
A reusable SAS macro solution for streamlining file archiving and extraction in a Windows environment.

## Features
- Archive selected files or use wildcards.
- Configure source and destination directories.
- Create password-protected or unprotected archives.
- Optionally delete source files after archiving.
- Extract archived files to a specified destination.

## Technical Skills
- SAS macro programming
- Macro parameters and conditional logic
- Windows command execution
- File management automation

## Business Value
Standardizes recurring file-management tasks and reduces repetitive manual steps through reusable, configurable macros.

## Requirements
- SAS in a compatible Windows environment
- WinRAR installed and accessible
- Appropriate permissions for the relevant directories

## Security Note
The public version of this project must not contain confidential banking information, internal server paths, credentials, or sensitive data.
