# Food Bacteria Counts: Chilled vs. Not-Chilled Samples

## Project overview
This R case study examines bacterial counts (CFU/g) in 96 food samples, comparing chilled and not-chilled groups and exploring variation across observed temperature categories.

**Data status:** This project package uses the dataset supplied for this analysis. Confirm that you have permission to publish it before making the repository public. If it is not cleared for public release, replace `data/bacteria_data.csv` with a synthetic dataset and label it accordingly.

## Research questions
1. How do bacterial counts differ descriptively between chilled and not-chilled samples?
2. Are CFU/g distributions consistent with normality within each treatment group?
3. Is there statistical evidence of a difference in CFU/g between treatment groups?
4. Do CFU/g distributions differ across temperature categories within the chilled and not-chilled groups?

## Methods
- Descriptive statistics: sample size, mean, standard deviation, median, IQR, minimum, maximum, skewness, and kurtosis.
- Visualization: boxplots on a `log10(CFU/g + 1)` scale to accommodate zero counts and strongly right-skewed data.
- Shapiro-Wilk normality tests.
- Wilcoxon rank-sum test for chilled versus not-chilled groups.
- Kruskal-Wallis tests within each treatment group for temperature-category differences.
- Pairwise Wilcoxon tests with Bonferroni adjustment for temperature categories within each treatment group.

## Preliminary findings from the supplied results
The supplied analysis reports 35 chilled samples and 61 not-chilled samples. The observed distributions are strongly right-skewed, and the supplied results report a statistically significant difference between treatment groups (Wilcoxon rank-sum p = 3.00e-06) and temperature-group differences (Kruskal-Wallis p = 3.10e-03 in the reported combined analysis).

These are results from the supplied project materials; rerun the included script to regenerate the outputs and check any discrepancies before publication. Do not interpret the test statistic as a multiplicative ratio of bacterial counts. Statistical significance does not establish causality, food safety status, or population representativeness.

## Reproducibility
1. Install R and RStudio.
2. Open `bacteria-analysis.Rproj` or the folder in RStudio.
3. Run `R/analysis.R`.
4. Outputs are written to `results/tables/` and `results/figures/`.

The script uses relative file paths, so it does not depend on a particular computer's `C:/Users/...` directory.

## Limitations
- The sample may not be representative of the wider food supply.
- The sample sizes within temperature categories are modest and uneven.
- Temperature and treatment are associated by design in these data, so temperature effects should not be interpreted as causal.
- The supplied report notes an imputed temperature of 8.5°C for chilled vegetables and exclusion of pasteurized milk from an earlier analysis; verify these decisions against the final data before publication.
- Check the exact test outputs generated by the script against the supplied report before reporting final conclusions.
